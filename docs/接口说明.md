完整、最新的说明以官网 [接口文档](https://kuaikejiance.com/api-docs) 为准。以下 `{BASE}` 代表 `https://kuaikejiance.com/open/v1`，所有请求都要带请求头 `Authorization: Bearer 您的密钥`。

## 查询额度

`GET {BASE}/balance`

| 返回字段 | 类型 | 说明 |
|---|---|---|
| quota | 数字 | 当前可用额度（条） |
| paidQuota | 数字 | 其中来自充值的额度 |
| giftQuota | 数字 | 其中来自赠送的额度 |

## 空号检测

批量空号检测，结果分为实号、空号、沉默号、风险号等。单次 2,000 ~ 200,000 个号码（去重后）。任务同时会出现在网页的“检测记录”里。

### 提交检测

`POST {BASE}/empty/tasks`

```json
{ "phones": ["13800138000", "13912345678"], "requestId": "order-20260101-0001" }
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| phones | 字符串数组 | 是 | 11 位大陆手机号，单次 2,000 ~ 200,000 个（去重后） |
| requestId | 字符串 | 否 | 您自己生成的请求编号（8~64 位字母、数字、下划线、短横线）。同一编号重复提交只处理一次、只扣一次额度 |

返回 `taskId`。重复号码会自动去重，按去重后的有效号码数扣额度。

### 查询进度

`GET {BASE}/empty/tasks/{taskId}`

```json
{
  "code": 0,
  "data": {
    "taskId": "…", "status": "done", "total": 2, "done": 2,
    "counts": { "active": 1, "empty": 1, "silent": 0, "risk": 0, "stopped": 0, "unknown": 0 },
    "chargedQuota": 2
  }
}
```

| 返回字段 | 类型 | 说明 |
|---|---|---|
| taskId | 字符串 | 任务编号 |
| status | 字符串 | `queued` 排队中、`running` 检测中、`done` 已完成、`failed` 失败（不扣额度） |
| total / done | 整数 | 有效号码总数 / 已检测数 |
| counts.active | 整数 | 实号数量 |
| counts.empty | 整数 | 空号数量 |
| counts.silent | 整数 | 沉默号数量 |
| counts.risk | 整数 | 风险号数量 |
| counts.stopped / counts.unknown | 整数 | 停机 / 未知数量 |
| chargedQuota | 数字 | 实际扣除的额度（条，完成后给出） |

### 取某一类号码

`GET {BASE}/empty/tasks/{taskId}/result?kind=empty`

| kind | 含义 |
|---|---|
| active | 实号（正常使用） |
| empty | 空号 |
| silent | 沉默号 |
| risk | 风险号 |
| stopped | 停机 |
| unknown | 未知 |

| 返回字段 | 类型 | 说明 |
|---|---|---|
| kind | 字符串 | 本次返回的类别 |
| count | 整数 | 这一类的号码数量 |
| phones | 字符串数组 | 这一类的全部号码 |

任务完成后才能取结果。

## 高级空号检测

对每一个号码逐个核验，检测结果更准确：实号、空号、沉默号、风险号。未知结果不扣额度。单次最多 200,000 个号码。

| 方法 | 地址 | 说明 |
|---|---|---|
| POST | `{BASE}/empty-plus/tasks` | 提交检测，参数同空号检测（phones 最多 200,000 个） |
| GET | `{BASE}/empty-plus/tasks/{taskId}` | 查询进度，`counts` 含 active / empty / silent / risk / unknown |
| GET | `{BASE}/empty-plus/tasks/{taskId}/result?kind=empty` | 取某一类号码，kind 为 active / empty / silent / risk / unknown |

提交时先按号码数预扣，检测结束后自动退回未知结果的部分。

## 实时空号检测

实时查询号码当前状态（正常、空号、停机、关机等）。没查出结果（未检出）的号码不扣额度。

### 即查即回

`POST {BASE}/realtime/check`，单次 1 ~ 20 个号码，一般 1 ~ 5 秒返回。

```json
{
  "code": 0,
  "data": {
    "taskId": "…", "status": "done", "total": 1, "done": 1,
    "chargedQuota": 50, "balanceQuota": 128450,
    "results": [
      { "mobile": "13800138000", "carrier": "中国移动", "status": "ok",
        "text": "正常", "ported": false, "charged": true }
    ]
  }
}
```

| 返回字段 | 类型 | 说明 |
|---|---|---|
| results[].mobile | 字符串 | 号码 |
| results[].carrier | 字符串 | 运营商 |
| results[].status | 字符串 | 检测结果，取值见下表 |
| results[].text | 字符串 | 检测结果的中文说明 |
| results[].ported | 布尔 | 是否携号转网 |
| results[].charged | 布尔 | 这个号码是否扣额度 |
| chargedQuota / balanceQuota | 数字 | 本次扣除的额度 / 当前可用额度（条） |

| status | 含义 | 是否扣额度 |
|---|---|---|
| ok | 正常 | 扣 |
| empty | 空号 | 扣 |
| stop | 停机 | 扣 |
| off | 关机 | 扣 |
| busy | 通话中 | 扣 |
| ported | 携号转网 | 扣 |
| other | 其他 | 扣 |
| fail | 未检出 | 不扣 |
| skip | 暂不支持该号段 | 不扣 |
| pending | 还在检测中（仅批量任务） | — |

### 批量任务

| 方法 | 地址 | 说明 |
|---|---|---|
| POST | `{BASE}/realtime/tasks` | 请求内容同上，单次最多 100,000 个；立即返回 taskId |
| GET | `{BASE}/realtime/tasks/{taskId}` | 查询进度，建议每 2 ~ 5 秒一次 |
| GET | `{BASE}/realtime/tasks/{taskId}/result?offset=0&limit=1000` | 分页取结果，limit 默认 1000，最多 5000；每一项格式与即查即回相同 |

提交时先按号码数预扣额度，检测结束后自动退回未检出部分。

## 错误码

出错时 HTTP 状态码与 `code` 一起返回，`message` 里有中文说明。

| HTTP | code | 含义 | 怎么处理 |
|---|---|---|---|
| 400 | 4000x | 请求内容不对（号码为空、数量超限等） | 按 message 提示修改后重试 |
| 401 | 40101 / 40102 | 没带密钥，或密钥无效、已删除 | 检查请求头；必要时重新创建密钥 |
| 402 | 40200 | 额度不足 | 充值后重试 |
| 403 | 40330 | 来源 IP 不在允许范围内 | 修改密钥允许的 IP（删除后重建） |
| 403 | 40310 / 40331 ~ 40333 | 账号未实名、不可用，或该接口未开放 | 联系客服 |
| 404 | 40400 | 任务不存在，或接口地址写错 | 核对 taskId 与地址 |
| 409 | 40900 / 40901 | 任务还没完成，或账户额度刚好有变动 | 稍后重试 |
| 429 | 42900 / 42901 | 请求太频繁，或连续输错密钥 | 放慢速度；输错密钥需等 5 分钟 |
| 503 | 50300 | 该项业务暂未开通 | 联系客服 |
| 5xx | 50000 / 5020x | 服务暂时不可用 | 用同一个 requestId 稍后重试，不会重复扣额度 |
